# 家庭升為 tab,規劃收進「我的」,每頁工具列最多三顆

取代 ADR-0003。tab 改成總覽、交易、帳戶、家庭、統計，仍是 5 個，不會出現「更多」溢位。原本的「規劃」(週期收支、儲蓄目標、現金流預測)收進「我的」的第二個分頁;機器人記帳、外觀、登出和版本留在第一個分頁「設定」，每次打開都先顯示「設定」。帳號按鈕改成頭像，每個 tab 主頁面右上角都有，打開同一個「我的」sheet。家庭有自己的畫面和動作，藏在 sheet 裡太深，所以升為 tab。

為了放得下那顆頭像，每頁 toolbar 最多 3 顆按鈕、不放「…」:HIG 說 More 選單「only add this menu if you really need it」。放不下的動作搬進列表：交易的「匯出 CSV」在列表最底下，帳戶的「ATM 提款／轉帳」在摘要卡最下面。**選單是最後選項**:pull-down 至少 3 項才用(HIG Pull-down buttons);表單裡 2~5 個選項用內嵌選擇列(`.pickerStyle(.inline)`,`body` 字級，點一下就選);選項多的分類直接攤開成格，帳戶、日期這類多或不固定的推入清單頁。分類攤開成格是**刻意偏離** HIG(超過約 5 個選項建議用 pop-up button),理由是少一次點擊。字級沿用現有 text style，不新增，分段控制仍只用在既有的三個地方。

## Considered Options

- **維持 ADR-0003**(帳號只在總覽、家庭留在 sheet):總覽以外的頁面找不到「我的」，家庭仍藏得深。
- **每頁工具列加一顆帳號，其餘照舊**:交易、帳戶頁變 4 顆，超過本專案「每頁最多 3 顆」的做法。
- **固定「主要動作 · … · 帳號」**:每頁位置一致，但篩選、轉帳要多點一層，且 HIG 建議 More 選單非必要不加。
- **表單選擇用分段控制**:省高度，但字比現在小一級，推翻 #65，大字級容易截斷。

## Consequences

- 到「儲蓄目標」從 2 下(規劃 tab → 項目)變 3 下(頭像 → 規劃分頁 → 項目);登出、改外觀仍是 2 下。
- 5 個 tab 的 toolbar、`ForecastUITests`(依賴「規劃」tab)、截圖巡覽都要改;`DESIGN.md`「導覽」「字型與數字」「元件對照」和 `docs/parity.md` 第 17 項要同步。
- 視角和帳戶檢視範圍維持 toolbar 選單(各 3 個選項):選過的會被記住，平常不用切換。
