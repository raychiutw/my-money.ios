# 首頁功能入口只放 tab 沒有的功能

> **修訂 [ADR-0010](0010-home-feature-entries.md)**:入口格從 8 格縮成 3 格;其餘決定不變。

ADR-0010 的入口格有 8 格,其中記帳、帳戶、信用卡、家庭、統計都只是切到底下 tab bar 已有的 tab,等於同一件事兩個入口;週期收支、儲蓄目標、現金流預測才是原本藏在「我的」裡、找不到的功能。

## Decision

- 入口格只留週期收支、儲蓄目標、現金流預測(#196)。
- 總覽不再為了入口的數字去抓本月筆數與家庭分攤,少兩個請求。
- 信用卡待繳仍在三格數字磚,帳戶仍在帳戶區塊,資訊沒有遺失。

## Consequences

新增的功能若沒有 tab,才放進入口格;有 tab 的不放。
