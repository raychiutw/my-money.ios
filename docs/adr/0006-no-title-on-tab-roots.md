# 五個 tab 的首頁不顯示標題與副標題，篩選狀態改由篩選按鈕的圖示表達

總覽、交易、帳戶、家庭、統計五個 tab 的首頁最上面原本有一塊大標題(外加導覽列副標題寫著目前的篩選範圍)，佔掉可觀的空間;tab bar 已經說明目前在哪個 tab，標題是重複的資訊。使用者要求移除，而且**完全不在別處顯示範圍文字**。這推翻了 `DESIGN.md`「導覽列副標題一律顯示目前的範圍」的規範(HIG Searching 的「Clearly display the current scope」)。

## Considered Options

- **小標題置中(inline)並保留副標題**:不佔額外高度，但標題文字還在，三顆按鈕的工具列在大字級會擠。
- **把範圍放到清單最上面一列**:狀態一眼看得到，但仍佔一列空間，使用者沒有選。
- **完全移除，篩選按鈕套用篩選時改實心圖示**(採用):畫面最乾淨;「是不是被篩選過」用圖示狀態表達，不用文字，VoiceOver 仍念按鈕名稱與目前的選擇。

## Consequences

- 使用者看不到篩選的**具體內容**(哪個視角、哪段日期)，只看得到「有套用篩選」。要知道內容得點開篩選按鈕;VoiceOver 使用者直接聽得到(按鈕的值)。這是使用者明確接受的取捨。
- 「非預設」的判斷:視角或檢視範圍不是「全部」;交易頁還包含起迄日不是本月 1 號到今天、類型或分類不是全部、搜尋關鍵字非空白(#107)。
- 推入頁(週期收支、儲蓄目標、信用卡詳細頁等)與所有 sheet 的導覽列標題不變，因為它們需要「現在在哪一層」的脈絡和返回鍵。
- 總覽的問候(依時間的早安、午安、晚安，parity 原第 21 項)一併移除。
- UI 測試斷言導覽列副標題的地方，改成斷言篩選按鈕的 VoiceOver 值。
