# 我的記帳本(my-money.ios)

家庭共同記帳 app「我的記帳本」的 iOS 原生版(SwiftUI)，共用 [my-money](https://github.com/onion523/my-money) web 版的後端 API。功能與 web 版對等，介面遵守 Apple Human Interface Guidelines。

- 最低 iOS 26.0,用 Xcode 27 建置,iPhone 與 iPad 都支援
- 透過 TestFlight 內部測試發佈
